# DeadAir Cut

Windows video editor that removes silent intervals locally.

[Download the latest installer](https://github.com/xnatta/DeadAirCut/releases/latest)

- Drag a video in, analyze silence, preview the edited video, then export MP4.
- Dark and light themes; play/pause, seeking and volume in preview.
- Click Update once to check, download, verify and install a newer stable version.
- Preserves original videos, settings and the selected edits across upgrades.
- No Git, Python or .NET installation required on the user's PC.

A new PC needs internet on first video use to download the verified video engine
from its original publisher (about 115 MB). An upgrade from 1.0.0 preserves the
existing engine. Video processing itself stays on the user's PC.

This repository distributes installers, release notes and checksums.
The application project is maintained locally. Windows x64.
